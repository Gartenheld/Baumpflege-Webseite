# Vorschaubild zum Teilen (Open Graph)

`og-standard.html` ist die Vorlage für `public/og-standard.jpg` (1200 x 630 Pixel). Das Bild erscheint,
wenn jemand einen Link zur Website per WhatsApp, Facebook oder E-Mail teilt und die Seite kein eigenes Foto hat.
Seiten mit einem Foto in `src/bilder` verwenden automatisch einen Ausschnitt dieses Fotos.

Neu erzeugen: `og-standard.html` in Chrome öffnen, Fenster auf 1200 x 630 stellen (Entwicklertools, Gerätemodus),
Screenshot speichern und als JPEG unter `public/og-standard.jpg` ablegen. Ziel: unter 300 KB.
